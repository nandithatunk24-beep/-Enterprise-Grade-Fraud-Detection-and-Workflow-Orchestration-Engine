Transaction Safety Monitor

The app simulates a person-to-person transfer, evaluates a set of explicit IF–ELSE rules, classifies the resulting score and stores the outcome for later review.

How evaluation works

The same rules are applied automatically to each submitted transfer.

01

Capture details

Collect sender, recipient, amount, location and transaction date/time. The user does not select a risk level or final action.

02

Apply rules

Check amount, late-night timing, whether a location is new in saved sender history, and earlier transfers in the previous hour.

03

Classify score

0–29 is Low, 30–59 is Medium, and 60 or above is High. The prototype maps these levels to Approve, Review and Block suggestions.

04

Explain & save

Show triggered rules, save the score and result to a local SQLite database, and make records searchable in history.

Scope and limitations

This is a simulated, rule-based academic prototype. It uses locally saved transaction history and a SQLite database by default. It does not connect to banks, move real funds, or use machine learning. The rule weights, score boundaries and time window are explicit prototype assumptions and should not be represented as validated banking policy.
